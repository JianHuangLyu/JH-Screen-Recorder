# JH Camera 錄影程式 v2.31

Windows 螢幕錄影工具，可錄製全螢幕或自訂範圍，並同時擷取系統播放聲音與麥克風。安裝檔已包含 FFmpeg，不需另外下載。

## 系統需求

- Windows 10／11 64 位元。
- 建議保留足夠的硬碟空間；錄製時間越長，檔案越大。
- Windows 版安裝檔不能直接用於 macOS 或 Linux。

## 安裝方法

1. 雙擊 `JH錄影程式安裝檔_v2.31.exe`。
2. 確認安裝位置與捷徑選項。桌面捷徑預設勾選，開始功能表捷徑預設不勾選。
3. 按「安裝」，完成後開啟 `JH Camera錄影程式`。

## 使用方法

1. 選擇「全螢幕」或「自訂框選」，也可拖曳紅色邊框調整範圍。
2. 程式會自動選取系統聲音與麥克風；需要時按「重新偵測音訊」。
3. 只想保留麥克風人聲時，勾選「只錄製人聲（RNNoise＋VAD）」；需要完整麥克風環境聲時取消勾選。
4. 按「開始錄影」，再使用迷你工具列暫停、繼續或停止。
5. 停止後等待處理進度完成，MP4 影片會儲存在指定資料夾。

## UI 互動編輯器

1. 開啟 `JHCamera_UI編輯器.html`，不需安裝或啟動伺服器。
2. 可新增、複製、刪除、拖曳及縮放元件，也能修改文字、類型、位置、字型、顏色與圖層。
3. 完成後按「匯出給 Codex 修改」，產生 `JHCamera_UI設定.json`。
4. JSON 只保存設計，不會直接修改已安裝程式；需將設定套用至原始碼後重新打包。

鍵盤快捷鍵：`Ctrl+Z` 復原、`Ctrl+Y` 重做、`Ctrl+D` 複製、`Delete` 刪除元件。

## 錄影時間與檔案

- 程式沒有設定固定錄影時間上限。
- 長時間錄影會增加硬碟用量、記憶體與處理負擔，停止後的封裝時間也可能變長。
- 錄影期間會先建立 MKV 暫存片段，停止後再快速封裝或合併成 MP4。
- 建議長時間錄影前確認輸出磁碟空間，並先短錄測試畫面與音訊。

## 技術說明

- 介面：PowerShell／Windows Forms。
- 畫面：FFmpeg `gdigrab`、H.264 高畫質輸出；FPS 依螢幕更新率、電腦效能與錄影範圍自動選擇 30 或 60。
- 系統聲音：NAudio WASAPI Loopback，可錄製瀏覽器、播放器及一般程式的播放聲音。
- 麥克風：DirectShow／OpenAL 自動偵測。
- 人聲模式：RNNoise 降低背景雜音，WebRTC VAD 判斷人聲；非人聲替換成等長靜音以維持同步。
- 音訊：48 kHz AAC，混音後使用限制器降低爆音風險。
- 隱私：錄影與音訊處理均在本機執行，不會自動上傳內容。

## 原始碼建置

1. 使用 Windows 10／11 64 位元下載或 clone 本 repo。
2. 執行 `setup_ffmpeg.ps1`，下載本機建置所需的 FFmpeg。
3. 執行 `build-installer.ps1`。
4. 完成後會在專案根目錄產生 `JH錄影_v版本.exe` 與 `JH錄影程式安裝檔_v版本.exe`；建置暫存檔會自動清除。

一般使用者可直接從 GitHub Releases 下載安裝檔，不需自行建置。

## 注意事項

- 人聲模式會保留麥克風收到的所有說話者，無法只辨識指定使用者。
- 系統聲音與「只錄製人聲」為不同管線；人聲過濾只套用在麥克風。
- 受 DRM 保護的影片或部分全螢幕獨佔程式可能無法擷取。
- 若麥克風輸入已破音，請降低 Windows 麥克風音量或裝置增益。
