三步完成 UI 修改

  1. 從上方切換「主視窗」、「錄製小工具列」或「處理進度窗」。
  2. 左側可以新增、複製或刪除元件；點選元件後可拖曳與縮放。
  3. 右側可以修改類型、控制項名稱、文字、位置、字型、顏色與狀態。
  4. 按「匯出給 Codex 修改」，把下載的 JHCamera_UI設定.json 交給我。

匯出檔會保留正式程式中的控制項名稱。我收到後會依照設定修改 recorder.ps1，再重新打包 Windows 安裝檔。
